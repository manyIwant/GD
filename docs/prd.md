# 需求文档

## 1. 应用概述

### 1.1 应用名称
高德星际·星际客运（游戏化版）

### 1.2 应用描述
对现有科幻主题星际旅行模拟Web应用进行全面游戏化升级与后端化改造，增加等级系统、每日任务、排行榜、飞船收藏、宇宙事件小游戏、飞行日志、每日签到、成就展示墙等游戏元素，接入Supabase实现用户认证、云存档、实时排行榜，优化响应式设计适配手机端与电脑端，提供Electron（DMG）和Capacitor（APK）打包配置。

---

## 2. 用户与使用场景

### 2.1 目标用户
- 喜欢科幻题材的游戏玩家
- 对星际旅行模拟感兴趣的用户
- 希望体验游戏化互动的Web应用用户

### 2.2 核心使用场景
- 用户通过游戏化任务与等级系统，持续参与星际旅行预订与航行
- 用户在航行中触发宇宙事件小游戏，增加互动乐趣
- 用户通过云端排行榜与其他玩家竞争，展示旅行成就
- 用户在手机端或电脑端随时访问应用，数据云端同步

### 3.2 功能说明

#### 3.2.1 登录/注册页
- 用户输入邮箱、密码完成注册或登录
- 支持游客模式（本地存档，不同步云端）
- 登录成功后跳转至首页，加载云端数据

#### 3.2.2 首页
- 展示用户当前等级、XP进度条、信用点余额
- 显示每日任务入口、排行榜入口、飞船收藏入口
- 保留原有快捷导航至航线、订单、通行证、监控、通讯页

#### 3.2.3 航线页
- 保留原有星球数据、飞船方案、动态定价、三体纪元展示
- 用户选择目的地、飞船方案，预订航班
- 预订成功后生成订单，扣除信用点，增加XP

#### 3.2.4 订单页
- 展示用户所有订单（进行中、已完成、已取消）
- 用户可查看订单详情、取消订单、启动航行

#### 3.2.5 通行证页
- 保留原有通行证功能
- 展示用户通行证状态、有效期、权益

#### 3.2.6 监控页
- 保留原有飞行监控功能
- 航行中实时显示飞船位置、剩余时间、休眠状态
- 航行中随机触发宇宙事件，弹出宇宙事件小游戏弹窗

#### 3.2.7 通讯页
- 保留原有通讯功能
- 展示系统消息、任务提示、成就通知

#### 3.2.8 等级与成就页
- 展示用户当前等级（见习宇航员→星际探险家→银河传说等）、XP进度、下一等级所需XP
- 展示成就奖章墙，已解锁成就高亮显示，未解锁成就灰色显示
- 用户点击成就查看解锁条件与奖励

#### 3.2.9 每日任务页
- 每天生成3个随机任务（如「今日预订飞往火星的航班」「完成一次航行」「签到」）
- 用户完成任务后点击领取，获得XP和信用点
- 任务状态由服务端生成与验证，防止刷取

#### 3.2.10 排行榜页
- 展示全球玩家排行榜，按累计光年数、完成航次、成就数排名
- 实时从云端同步数据
- 用户可查看自己排名与前100名玩家

#### 3.2.11 飞船收藏页
- 展示所有飞船皮肤，已解锁飞船可选择使用
- 未解锁飞船显示解锁条件（等级要求）
- 不同飞船具有特效和BUFF（如速度加成、信用点折扣）

#### 3.2.12 飞行日志页
- 展示用户所有已完成航行记录
- 每次抵达目的地生成一张星际明信片（包含目的地名称、抵达时间、飞船名称、航行光年数）
- 用户可查看历史明信片

#### 3.2.13 宇宙事件小游戏弹窗
- 航行中随机触发宇宙事件时弹出
- 小游戏类型：解码神秘信号（点击正确按钮）、躲避流星（滑动躲避障碍物）
- 完成小游戏获得额外XP或信用点

#### 3.2.14 成就解锁动画弹窗
- 用户解锁成就时弹出华丽动画
- 展示成就名称、图标、奖励

#### 3.2.15 星际明信片弹窗
- 航行抵达目的地时弹出
- 展示精美明信片，包含目的地图片、名称、抵达时间、航行数据

#### 3.2.16 每日签到功能
- 首页或通讯页展示签到入口
- 用户每日签到获得信用点，连续签到有额外奖励（如第7天双倍奖励）

## 4. 业务规则与逻辑

### 4.1 星际旅行者等级系统
- 用户通过完成航行、任务、成就获得XP
- XP累积达到阈值后自动晋升等级
- 等级段位：见习宇航员（0-999 XP）→星际探险家（1000-4999 XP）→银河传说（5000+ XP）
- 等级解锁隐藏目的地和飞船折扣

### 4.2 每日任务系统
- 每天0点（服务端时间）生成3个随机任务
- 任务类型：预订特定目的地航班、完成航行、签到、充值等
- 用户完成任务后点击领取，服务端验证后发放奖励
- 任务状态云端同步

### 4.3 星际排行榜
- 排行榜数据实时从Supabase云端同步
- 排名维度：累计光年数（light_years_traveled）、完成航次（orders_completed）、成就数（achievements_count）
- 用户完成航行或解锁成就后，数据自动上传云端更新排名

### 4.4 飞船收藏系统
- 飞船皮肤随等级解锁
- 用户选择飞船后，航行时应用对应特效和BUFF
- BUFF类型：速度加成（缩短航行时间）、信用点折扣（降低预订费用）

### 4.5 宇宙事件小游戏
- 航行中随机触发（概率30%）
- 小游戏难度根据用户等级调整
- 完成小游戏获得额外奖励，失败无惩罚

### 4.6 飞行日志与星际明信片
- 每次航行抵达目的地时，自动生成星际明信片
- 明信片数据存储至云端，用户可随时查看历史记录

### 4.7 每日签到
- 用户每日签到获得固定信用点（如100点）
- 连续签到天数累积，第7天、第30天等节点有额外奖励
- 签到状态云端同步

### 4.8 成就展示墙
- 成就解锁时触发华丽动画弹窗
- 成就奖章墙在等级与成就页展示，已解锁成就高亮

### 4.9 云端数据同步（Supabase）
- 用户注册/登录后，所有数据（订单、成就、余额、等级、XP、任务状态、签到记录）云端同步
- 游客模式下数据仅存储本地，不同步云端
- 用户切换设备登录后，自动加载云端数据

### 4.10 响应式设计
- 使用CSS媒体查询和flex/grid布局，适配手机端（宽度<768px）与电脑端（宽度≥768px）
- 手机端：单列布局，按钮与文字放大，弹窗全屏显示
- 电脑端：多列布局，侧边栏导航，弹窗居中显示

### 4.11 打包配置
- 提供electron-builder配置文件（electron-builder.json），用户可自行构建DMG安装包
- 提供capacitor.config.json配置文件，用户可自行构建APK安装包

## 5. 异常与边界情况

| 场景 | 处理方式 |
|------|----------|
| 用户未登录访问需登录功能 | 跳转至登录页，提示「请先登录」 |
| 用户信用点不足预订航班 | 弹出充值弹窗，提示「信用点不足，请充值」 |
| 用户取消进行中的订单 | 扣除部分信用点作为取消费用，订单状态变更为已取消 |
| 航行中网络断开 | 本地缓存航行状态，网络恢复后同步至云端 |
| 每日任务已完成但未领取 | 任务状态保留至当天23:59:59，次日0点重置 |
| 用户连续签到中断 | 连续签到天数重置为0，重新开始累积 |
| 宇宙事件小游戏加载失败 | 跳过小游戏，航行正常继续 |
| 排行榜数据加载失败 | 显示「排行榜暂时无法加载，请稍后重试」 |
| 用户等级达到上限 | XP继续累积，但等级不再晋升 |
| 飞船皮肤解锁条件未满足 | 飞船显示为灰色，点击提示「需达到XX等级解锁」 |

## 6. 验收标准

1. 用户在登录页输入邮箱、密码完成注册或登录，成功后跳转至首页
2. 用户在首页查看当前等级、XP进度、信用点余额，点击每日任务入口进入每日任务页
3. 用户在每日任务页完成一个任务（如「今日预订飞往火星的航班」），点击领取获得XP和信用点
4. 用户在航线页选择目的地、飞船方案，预订航班成功，生成订单并扣除信用点
5. 用户在订单页启动航行，监控页实时显示飞船位置与剩余时间
6. 航行中触发宇宙事件小游戏，用户完成小游戏获得额外奖励
7. 航行抵达目的地，弹出星际明信片弹窗，展示明信片内容
8. 用户在飞行日志页查看历史明信片记录
9. 用户在排行榜页查看全球玩家排名，确认自己排名位置
10. 用户在飞船收藏页选择已解锁飞船，下次航行时应用对应特效和BUFF
11. 用户在等级与成就页查看成就奖章墙，解锁新成就时弹出华丽动画
12. 用户在手机端访问应用，页面布局自动适配为单列布局，操作流畅
