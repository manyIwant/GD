# 需求文档

## 1. 应用概述

### 1.1 应用名称
高德星际·星际客运（游戏化版）

### 1.2 应用描述
对现有科幻主题星际旅行模拟Web应用进行全面游戏化升级与后端化改造，增加等级系统、每日任务、排行榜、飞船经验累积与属性升级系统、宇宙事件小游戏、飞行日志、每日签到、成就展示墙、限时活动、转盘抽奖等游戏元素，接入Supabase实现用户认证、云存档、实时排行榜，优化响应式设计适配手机端与电脑端，提供Electron（DMG）和Capacitor（APK）打包配置。

---

## 2. 用户与使用场景

### 2.1 目标用户
- 喜欢科幻题材的游戏玩家
- 对星际旅行模拟感兴趣的用户
- 希望体验游戏化互动的Web应用用户

### 2.2 核心使用场景
- 用户通过游戏化任务与等级系统，持续参与星际旅行预订与航行
- 用户在航行中触发宇宙事件小游戏，增加互动乐趣
- 用户通过云端排行榜与其他玩家竞争，展示旅行成就
- 用户在手机端或电脑端随时访问应用，数据云端同步
- 用户通过选择飞船公司并累积经验，自主选择属性升级路线
- 用户参与限时活动、转盘抽奖等玩法获取奖励

### 3.2 功能说明

## 4. 业务规则与逻辑

### 4.1 星际旅行者等级系统
- 用户通过完成航行、任务、成就获得XP
- XP累积达到阈值后自动晋升等级
- 等级段位：见习宇航员（0-999 XP）→星际探险家（1000-4999 XP）→银河传说（5000+ XP）
- 等级解锁隐藏目的地和飞船折扣

### 4.2 每日任务系统
- 每天0点（服务端时间）生成3个随机任务
- 任务类型：预订特定目的地航班、完成航行、签到、充值等
- 用户完成任务后点击领取，服务端验证后发放奖励
- 任务状态云端同步

### 4.3 星际排行榜
- 排行榜数据实时从Supabase云端同步
- 排名维度：累计光年数（light_years_traveled）、完成航次（orders_completed）、成就数（achievements_count）
- 用户完成航行后，累计光年数自动更新：累计光年数 = 原累计光年数 + 本次航行光年数
- 数据更新后立即同步至云端，排行榜实时刷新

### 4.4 飞船经验累积与属性升级系统
- 用户选择某家公司的飞船后，每次乘坐该公司飞船完成航行，该公司飞船经验值增加
- 经验值增加量根据航行光年数计算：经验值增加量 = 航行光年数 × 经验系数
- 经验值达到阈值后，飞船等级提升，获得属性升级点数
- 用户在属性升级界面选择升级路线（火力、防御力、速度、续航等），消耗升级点数解锁节点
- 每条升级路线包含多个等级节点，节点解锁后对应属性提升
- 属性提升对航行产生实际影响：
  + 速度提升：缩短航行时间（如速度+10%，航行时间-10%）
  + 续航提升：降低燃料消耗或增加航行距离
  + 火力提升：宇宙事件小游戏中获得优势
  + 防御力提升：降低航行中遭遇危险的概率
- 不同公司飞船的升级路线与属性加成不同，用户可根据偏好选择

### 4.5 宇宙事件小游戏
- 航行中随机触发（概率30%）
- 小游戏难度根据用户等级调整
- 完成小游戏获得额外奖励，失败无惩罚

### 4.6 飞行日志与星际明信片
- 每次航行抵达目的地时，自动生成星际明信片
- 明信片数据存储至云端，用户可随时查看历史记录
- 明信片内容包含：
  + 目的地高清图片
  + 目的地名称
  + 抵达时间
  + 飞船名称
  + 航行光年数
  + 航行编号（格式：SJ-YYYYMMDD-XXXXX，其中YYYYMMDD为日期，XXXXX为当日订单序号）
  + 目的地特色信息（根据目的地预设，如「火星：红色星球，人类第二家园」「木星：气态巨行星，拥有壮观的大红斑」）
  + 飞行时长（根据航行开始时间与抵达时间计算，格式：X天X小时）
  + 飞船徽章图标（根据飞船公司预设）
  + 本次航行解锁的成就名称与图标（如有，从用户成就列表中提取本次航行新解锁的成就）
  + 随机星际语录（从预设语录库中随机选取或根据目的地特点选取，语录库包含多句风格不同的星际语录，如「穿越星海，抵达梦想的彼岸」「在无尽的宇宙中，每一次旅行都是一次重生」「星辰大海，永不止步」「探索未知，书写传奇」「宇宙浩瀚，我心永恒」等）
  + 科幻风格装饰元素
- 明信片支持打印（调用浏览器打印功能）或下载为图片（PNG/JPG格式，分辨率1920x1080）

### 4.7 每日签到
- 用户每日签到获得固定信用点（如100点）
- 连续签到天数累积，第7天、第30天等节点有额外奖励
- 签到状态云端同步

### 4.8 成就展示墙
- 成就解锁时触发华丽动画弹窗
- 成就奖章墙在等级与成就页展示，已解锁成就高亮

### 4.9 云端数据同步（Supabase）
- 用户注册/登录后，所有数据（订单、成就、余额、等级、XP、任务状态、签到记录、累计光年数、飞船经验与属性升级数据）云端同步
- 游客模式下数据仅存储本地，不同步云端
- 用户切换设备登录后，自动加载云端数据

### 4.10 用户封禁机制
- 管理员在管理控制台执行封禁操作后，用户封禁状态立即写入数据库
- 被封禁用户尝试登录时，系统检查封禁状态，若已封禁则拒绝登录并提示「您的账号已被封禁，无法登录」
- 已登录用户被封禁后，下次请求时检测到封禁状态，强制下线并跳转至登录页，提示「您的账号已被封禁」

### 4.11 飞船方案定价逻辑
- 基础票价根据目的地距离（光年数）计算：基础票价 = 光年数 × 单位光年价格系数
- 不同品牌/舱位在基础票价上增加加成：最终票价 = 基础票价 × 品牌/舱位加成系数
- 品牌/舱位加成系数示例：经济舱1.0、商务舱1.5、头等舱2.0
- 机上服务项目单独计费：跳伞装置500信用点、早饭50信用点、午饭80信用点、晚饭80信用点
- 用户预订时，总费用 = 最终票价 + 机上服务费用总和

### 4.12 银河星图状态逻辑
- 用户对星球执行「曲速前往」并抵达后，该星球状态更新为「已到达」
- 已到达的星球在银河星图上显示「已到达」标识，不再显示「曲速前往」按钮
- 未到达的星球显示「曲速前往」按钮
- 修复星图逻辑问题：确保状态更新准确、交互流畅、数据同步及时

### 4.13 路线预览图生成逻辑
- 路线预览图基于真实宇宙数据生成，星球位置反映真实位置关系
- 图中标注出发地、目的地、中转站（如有）
- 各段光年数单独标注：出发地→中转站X光年、中转站→目的地Y光年
- 总光年数 = 各段光年数之和

### 4.14 限时活动系统
- 限时活动由服务端定期生成，包含活动时间、活动规则、活动奖励
- 活动类型：双倍XP活动、特殊目的地开放、限时任务挑战等
- 用户完成活动任务后，服务端验证并发放奖励
- 活动结束后自动下线，新活动定期上线

### 4.15 转盘抽奖系统
- 用户消耗信用点或抽奖券参与转盘抽奖
- 转盘奖励由服务端配置，包含多种奖励（信用点、XP、飞船经验、道具、稀有成就等）
- 用户点击抽奖按钮后，服务端随机生成中奖结果，返回前端展示
- 中奖奖励自动发放至用户账户，数据云端同步

### 4.16 数据合理性与计算规则
- 所有数据（光年数、票价、XP、信用点、飞船经验等）使用专门函数计算，确保合理性与一致性
- 光年数基于真实天文数据或合理估算值
- 票价、XP、信用点等数值符合游戏平衡性与逻辑性

### 4.17 响应式设计
- 使用CSS媒体查询和flex/grid布局，适配手机端（宽度<768px）与电脑端（宽度≥768px）

## 5. 异常与边界情况

| 场景 | 处理方式 |
|------|----------|
| 用户未登录访问需登录功能 | 跳转至登录页，提示「请先登录」 |
| 被封禁用户尝试登录 | 拒绝登录，提示「您的账号已被封禁，无法登录」 |
| 已登录用户被封禁 | 下次请求时检测到封禁状态，强制下线并跳转至登录页，提示「您的账号已被封禁」 |
| 用户信用点不足预订航班 | 弹出充值弹窗，提示「信用点不足，请充值」 |
| 用户取消进行中的订单 | 扣除部分信用点作为取消费用，订单状态变更为已取消 |
| 航行中网络断开 | 本地缓存航行状态，网络恢复后同步至云端 |
| 每日任务已完成但未领取 | 任务状态保留至当天23:59:59，次日0点重置 |
| 用户连续签到中断 | 连续签到天数重置为0，重新开始累积 |
| 宇宙事件小游戏加载失败 | 跳过小游戏，航行正常继续 |
| 排行榜数据加载失败 | 显示「排行榜暂时无法加载，请稍后重试」 |
| 用户等级达到上限 | XP继续累积，但等级不再晋升 |
| 飞船经验达到上限 | 经验值继续累积，但等级不再提升 |
| 用户升级点数不足 | 提示「升级点数不足，请继续航行获取经验」 |
| 明信片打印失败 | 提示「打印失败，请检查打印机设置」 |
| 明信片下载失败 | 提示「下载失败，请稍后重试」 |
| 路线预览图加载失败 | 显示「路线预览图暂时无法加载，请稍后重试」 |
| 累计光年数更新失败 | 本地缓存更新数据，网络恢复后同步至云端 |
| 银河星图状态更新失败 | 本地缓存状态，网络恢复后同步至云端 |
| 限时活动加载失败 | 显示「活动暂时无法加载，请稍后重试」 |
| 转盘抽奖网络异常 | 提示「抽奖失败，请稍后重试」，不扣除抽奖消耗 |
| 属性升级数据同步失败 | 本地缓存升级数据，网络恢复后同步至云端 |

## 6. 验收标准

1. 用户在登录页输入邮箱、密码完成注册或登录，成功后跳转至首页
2. 用户在首页查看当前等级、XP进度、信用点余额，点击飞船经验与升级入口进入飞船经验与升级页
3. 用户在飞船经验与升级页选择某家公司飞船，查看当前经验值与等级，点击进入属性升级界面
4. 用户在属性升级界面选择速度升级路线，消耗升级点数解锁一个节点，确认升级成功
5. 用户在航线页选择目的地、飞船方案、机上服务，预订航班成功，生成订单并扣除信用点
6. 用户在订单页启动航行，监控页实时显示飞船位置与剩余时间
7. 航行抵达目的地，弹出星际明信片弹窗，展示明信片内容（包含航行编号、目的地特色信息、飞行时长、飞船徽章、本次航行解锁的成就、随机星际语录），用户点击「下载」按钮下载明信片图片
8. 用户在飞行日志页查看历史明信片记录，确认明信片内容丰富且风格多样
9. 用户在银河星图页查看深空背景地图，确认背景神秘浩瀚、科幻感强，对一个星球执行「曲速前往」并抵达后，该星球显示「已到达」状态
10. 用户在限时活动页查看当前活动，完成活动任务后领取奖励
11. 用户在转盘抽奖页消耗信用点参与抽奖，转盘旋转后展示中奖结果，奖励自动发放至账户
12. 用户在飞船经验与升级页确认乘坐某公司飞船完成航行后，该公司飞船经验值增加，等级提升后获得升级点数
